# LPY-DOS 2.0 需求记录（安装器与系统能力升级）

> 记录日期：2026-09-06
> 目标版本：2.0.0 —— 发行形态、引导链、文件系统、API、显示全面升级，属主版本号的史诗级变更
> 状态：需求由作者确认。按子项目逐个走「设计规格 → 实现计划 → 编码验证」，当前讨论子项目 1（引导加载器）

## 一、发行形态：5 张安装软盘

分发形态改为「安装盘套件」，取消独立 Live 软盘设定。第一张盘就是安装盘，BIOS 引导后直接进入 INSTALL 安装程序，不存在先启动一个 Live 系统再安装的路径。

| 盘号 | 名称 | 内容 |
| --- | --- | --- |
| 1 | 安装启动盘 | 引导扇区 + INSTALL 安装程序（引导后直接运行） |
| 2 | 基础系统组件 | IO.SYS、LPYDOS.SYS、COMMAND.COM、CONFIG.INI 等系统文件 |
| 3 | 工具与游戏 | 现有全部外部 .COM 程序（工具 / 图形 / 游戏 / 声音） |
| 4 | 硬件增强 + 语言包 | 硬件增强工具、语言包 |
| 5 | DOS 恢复盘 | 恢复环境，具体内容清单在设计阶段定稿 |

每次构建的产物：

- 5 张安装软盘镜像（FAT12 1.44MB）
- 1 个预装硬盘镜像的两种封装：IMG（裸扇区镜像）与 VMDK（VMware 虚拟盘，由 IMG 经 qemu-img 转换生成）。两者内容等同「已把 DOS 安装到硬盘」，直接写入介质即可引导进入系统

## 二、安装与换盘可靠性（硬性验收标准）

- 换盘提示必须醒目、明确到盘号与盘名；每次换盘后安装程序必须校验盘片身份（卷标或标记文件），错盘一律拒绝并重新提示
- 换盘过程中出现的任何异常——插错盘、中途拔盘、读取失败——必须进入受控错误路径：给出明确错误说明，允许重试 / 继续 / 中止。禁止死机、禁止自动重启、禁止静默损坏已写入硬盘的数据
- 验收方式：QEMU 全流程安装，包含插错盘与中途拔盘模拟，全程零挂机、零数据损坏

## 三、系统能力要求

- 程序格式：COM 程序加载器（v1 的 EXEC 已具备，保持兼容）；新增 MZ EXE 支持（EXE 头解析、重定位表处理、CS:IP / SS:SP 设定）
- 中断兼容：INT 21h（MS-DOS 服务集）、INT 22h（进程终止地址语义）、INT 80h（LPY-DOS 扩展服务接口；MS-DOS 对该号无标准定义，服务号分配在设计阶段定义）
- 文件系统：FAT12、FAT16、FAT32 全支持。软盘用 FAT12；硬盘分区按容量选择 FAT16 / FAT32
- 系统文件结构（对标 MS-DOS，替代 v1 的 LPYOS.SYS + LPYCMD.COM 双件套）：
  - IO.SYS —— 硬件初始化与驱动层，引导扇区直接加载的第一个系统文件
  - LPYDOS.SYS —— DOS 内核（对标 MSDOS.SYS），由 IO.SYS 接续加载
  - COMMAND.COM —— 命令解释器（替代 LPYCMD.COM）
  - CONFIG.INI —— 启动配置文件（设备、参数、shell 指定等），替代 v1 写死在代码里的配置
- 显示能力：VGA 文本模式（v1 已有）与图形模式；在 BIOS 支持时升级为 VBE（VESA BIOS Extension，QEMU 的 std VGA 提供 VBE 可作验证平台）

## 四、与 v1 现状的差距（基于当前代码核实）

- 引导：引导扇区仅支持 FAT12，几何参数写死 18 扇区/道、2 磁头（boot/boot.asm:159-166），内核文件名写死 `LPYOS   SYS`（boot/boot.asm:246），内核 32KB 硬上限（build.ps1:128），无分区表 / 硬盘引导能力
- 磁盘层：全部读写固定走引导盘（kernel/disk.asm:38、58 取 `[boot_drive]`），INT 25h/26h 的 AL 驱动器号被忽略，无第二驱动器与硬盘访问
- 文件系统：内核已支持 FAT12/FAT16（按每 FAT 扇区数自动识别，kernel/fat.asm:40-54），FAT32 完全缺失
- API：无 MZ EXE 加载；INT 21h 覆盖部分子功能；无 INT 80h 扩展接口
- 系统文件：LPYOS.SYS + LPYCMD.COM，无 IO.SYS 分层，无 CONFIG.INI
- 显示：文本模式与少量图形程序（经 INT 21h AH=70h..7Ah 图形功能），无 VBE
- 构建：单镜像 LPY-DOS.img，无多盘与预装盘产出

## 五、子项目拆解与推进顺序

每个子项目独立走「设计规格 → 实现计划 → 编码验证」周期，从子项目 1 开始：

1. 引导加载器改造 —— 两阶段引导、BPB 驱动几何、FAT16/FAT32 引导、IO.SYS 启动链、自有 MBR（由安装器写入硬盘）
2. 磁盘层多驱动器与分区支持 —— disk.asm 驱动器参数化、硬盘 INT 13h 访问、MBR/分区表解析、INT 25h/26h 按驱动器号分流
3. FAT32 文件系统 —— fat.asm 扩展，补齐三种 FAT 的目录与读写路径
4. 内核结构重组 —— 拆分 IO.SYS / LPYDOS.SYS / COMMAND.COM / CONFIG.INI，建立新启动链与配置解析
5. DOS API 兼容 —— MZ EXE 加载器、INT 21h 子功能补全、INT 22h 语义、INT 80h 扩展接口
6. 显示系统 —— VGA 图形模式整理与 VBE 支持
7. INSTALL 安装器 —— 5 盘安装流程、盘片身份校验、写 MBR / 分区 / FAT16(FAT32) / 系统文件、活动分区置位、受控错误路径
8. 构建系统改造 —— 一次产出 5 张安装盘镜像 + 预装 IMG + VMDK
9. 恢复盘定义 —— 盘 5 的内容与恢复能力清单

依赖关系：1 是 2/3/4 的前置（启动链定下来，系统文件布局才能定）；7 依赖 2、3；8 依赖 7；其余可并行。
